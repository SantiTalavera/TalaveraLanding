# TALAVERA brand asset

`talavera-white.png` is an unchanged copy of the user-approved official asset
`logov2-sinFondo-blanco - copia.png` (644 × 167, transparent PNG).

Use this asset for the white wordmark. Preserve its proportions and original
color; do not trace it, recreate it with typography, or recolor it with filters.
Its transparent margins are part of the source file.
